# 联网工具

## 这是什么

三个工具：`web_search`（搜索）、`web_fetch`（抓一个网页的正文）、`get_current_time`（当前时间）。

**这三个都是模型自己调用的，你不需要（也无法）手动点它们。**

## 一个前提：搜索要花钱的服务

`web_search` 和 `web_fetch` **只有在你配置了至少一家搜索服务时才会出现**。配置里没写 `search` 这一块，模型就没有这两个工具可用（它当然也不会知道外面发生了什么）。

可配的服务（见 [配置](configuration.md)）：

| 服务 | 要什么 | 现在能不能用 |
|---|---|---|
| `deepseek` | 你的模型服务本身就是 DeepSeek（**不用再买搜索 key**） | 能用 —— 见下一节的开启办法 |
| `zhipuai` | 付费 key（`api_key`） | 能用 |
| `kimi` | 付费 key（`api_key`） | 能用 |
| `searxng` | 自建服务地址（`base_url`） | **这一版用不了** —— 启动时会跳过它的连通性检查并直接当成不可用 |

`get_current_time` **不需要任何配置**，一直在。

## 不想另外买搜索 key：用 DeepSeek 自己的搜索

如果你本来就用 DeepSeek 的模型（`providers` 里那个 `base_url` 指向 `api.deepseek.com`），那么**不用再配任何搜索密钥**就能有 `web_search` —— 搜索由 DeepSeek 的服务端直接做。

**怎么开**：在配置文件的 `search` 那一块里加一项，内容可以是空的（键名就是 `deepseek`）：

```json
{
  "search": {
    "deepseek": {}
  }
}
```

就这一句。它表明"我知道我在开 DeepSeek 搜索"，用的密钥就是你在 `providers` 里已经填的那把（地址也用它）。你不加这一项，它就不出现。

也可以自己单独指定（和上面两种写法二选一，写了就以写的为准）：

```json
{
  "search": {
    "deepseek": {
      "api_key": "单独给搜索用的 key",
      "base_url": "https://api.deepseek.com/anthropic",
      "model": "deepseek-v4-flash"
    }
  }
}
```

| 键 | 含义 | 不写会怎样 |
|---|---|---|
| `api_key` | 搜索那次调用用的密钥 | 用你 `providers` 里那把（**前提**：那个 `base_url` 指向 `api.deepseek.com`） |
| `base_url` | 搜索那次调用用的地址 | 同上，用你 `providers` 里那个地址 |
| `model` | 搜索那次调用用的模型 | `deepseek-v4-flash` |

**一条安全规矩（重要）**：只有地址**确实指向 DeepSeek**（含 `api.deepseek.com`）时才会复用 `providers` 里那把密钥与那个地址。地址指向别处（比如某个自建网关）时：你没把上面两样都写全 → 这个后端**直接不可用，一个请求都不发**；你自己把 `api_key` 与 `base_url` 两样都写了 → 按你写的走（它没碰 `providers` 里的任何东西，所以不存在"把别家的密钥发出去"）。原因是 `providers` 里那把密钥可能是别家的 —— 把它发到一个未必是 DeepSeek 的地址上既是泄漏、也必然失败。

**代价**：DeepSeek 的搜索是在一次完整的模型调用里做的（官方叫服务端搜索）。实测一次约 **4 到 5.5 秒**，并且**按 token 计费**（实测一次查询约 7000 输入 + 1100 输出 token）—— 不是"买搜索额度"那种计费，是走你的模型账单。所以能少搜就少搜。

**已知限制**：

- **要几条由服务定**：服务端没有"要几条"这个参数，应用只能拿到结果之后再按你给的条数截断（一次通常返 10 条）。
- **摘要（每条结果下面那段正文）常常是空的**：只有被引用的网页才有摘录片段；没有片段时卡片里显示的是那条结果的**标题**（不是编的摘要）。日期字段实测也基本拿不到（返回里是空的）。
- **标题偶尔是乱码**：有些站点的中文标题传回来时编码被打错过（实测出现过），这时标题里会出现 `�`。
- **端点要对**：如果 `base_url` 是某个"兼容 Anthropic 但不支持服务端搜索"的网关，你会看到"这次调用没有触发服务端搜索"这类报错 —— 那种情况下在 `search.deepseek.base_url` 里单独指定 DeepSeek 的地址即可。
- **输出长度不再由应用钉死**：以前应用会给这次调用写死一个输出上限（2048 token，是个拍出来的数）；现在**不设这个参数**，由服务端按默认值（非思考模式 8K）执行。代价是极端情况下这次调用可能更慢、更贵；换来的是不会因为一个偏小的自定上限把结果砍掉 —— 真被服务端截断时，错误说明里会写明（见上面那张表里的 `stop_reason=max_tokens` 一行）。


## 在哪用

你只要在对话里正常提问。模型自己判断要不要搜、抓哪个链接。每次调用在对话里出现一张卡片，展开能看到搜索词、抓的网址和返回内容。

## 三个工具分别干什么

### `web_search` —— 搜索

| 参数 | 含义 |
|---|---|
| `query` | 搜索词（必填） |
| `providers` | 用哪几家服务；不填 = 全用 |
| `depth` | `basic` = 只要摘要（快）；`deep` = 抓全文（慢） |
| `max_results` | 最多几条，1 到 10，默认 5 |

返回结果会按服务分组；一条都没搜到时卡片上是 `No results found`，有结果时是 `<N> providers, <M> results`。

### `web_fetch` —— 抓一个网页

| 参数 | 含义 |
|---|---|
| `url` | 要抓的网址 |

返回的是**正文纯文本**（去掉了网页的导航、广告等结构）。搜索摘要不够时，模型会用它去读整篇文章。

### `get_current_time` —— 当前时间

没有参数。返回日期、时间、时区。系统提示词里已经告诉模型：**要精确时间就用这个工具**（模型的训练数据有截止日期，不问就不知道今天几号）。

## 出错时会看到什么

| 卡片上的结果 | 含义 | 怎么办 |
|---|---|---|
| `No search providers configured` | 一家搜索服务都没配 | 在配置里加 `deepseek`（哪怕是空的）、`zhipuai` 或 `kimi`，重启应用 |
| `Search query is empty` | 搜索词是空的（模型调用出错，很少见） | 重说一次你的问题 |
| `All providers failed: <服务名>: <原因>` | 搜索服务都不通：key 无效、欠费、超时、网络不通 | 按冒号后面的原因查；key 或余额问题要自己去服务商那边处理 |
| `All providers failed: deepseek: 这次调用没有触发服务端搜索（返回里没有 web_search_tool_result 块）（本次使用的地址：<地址>）` | DeepSeek 那边这次**压根没做搜索**（常见原因：`base_url` 指向的端点不支持服务端搜索） | 看括号里的**地址**是不是 DeepSeek 的；不是就在 `search.deepseek.base_url` 里单独指定 |
| `All providers failed: deepseek: 连接失败 — …（本次使用的地址：<地址>）` | 地址连不上（网络不通、端口没人监听、域名写错） | 看括号里的**地址**：是不是你要的那个端点；再确认本机网络 |
| `All providers failed: deepseek: HTTP <状态码> — <原因>（本次使用的地址：<地址>）` | 密钥或地址不对（401 之类） | 按状态码与原因查；**括号里的地址就是它这次实际用的地址**，配错了从这里能看出来 |
| `All providers failed: deepseek: 超时（90 秒内没有响应）（本次使用的地址：<地址>）` | DeepSeek 那次调用太久没回（超过 90 秒） | 重试一次；一直这样就看括号里的地址通不通 |
| `All providers failed: deepseek: 这次调用的输出被服务端截断了（stop_reason=max_tokens）…` | DeepSeek 那边的回答太长、被输出上限切断了，结果可能不全 | 重说一次、把问题问窄一点；或换一个输出更长的模型 |
| `Fetch failed: 响应体超过上限 10485760 字节，服务端声明 <N> 字节，正文未被读取；本次抓取的是 <网址>` | 这个页面太大（超过 10MB），**没有下载** | 换一个小一些的页面；这条是内存保护，不是内容裁剪 |
| `Fetch failed: internal address not allowed` | 想抓的是本机或内网地址（例如 localhost、127.0.0.1、192.168.x.x） | 这是**故意拦的**（防止模型去读你本机上的服务）；要抓公网地址 |
| `Fetch failed: URL scheme not allowed` | 网址不是 http/https（例如 `file://`） | 换 http/https 地址 |
| 卡片状态 `Error` | 上面任何一种失败 | 展开卡片看具体文案 |

## 结果被"截断"时会看到什么

工具结果太长时会被截短，**每一处截短都有交代，而且都给了拿回完整内容的办法** —— 这是这个版本改过的行为（以前有几处是悄悄少的）：

| 你会看到 | 意思 | 怎么拿回完整的 |
|---|---|---|
| 每个搜索后端一行 `<名字>: <N> results` | 有几个后端、各搜到几条 —— **这一行永远不会被省掉** | —— |
| `（本条预览因篇幅未显示，结果条数见上面一行）` | 这个后端的结果条数给了，但第一条的预览没地方放 | 让模型只搜这一个后端（`providers` 指定），或把问题问窄 |
| `... 以下后端只给出了条数、没给出预览：<后端名>（<N> 条）` | 哪些后端被省掉了、各多少条 —— **会点名**，不是只说"还有几个" | 同上 |
| `...[truncated middle of N chars]...` + `[tool_result body elided: N chars > threshold 8000; refetch via <工具> "<参数>"]` | 某次工具结果的正文太长，中间一段被略去（保头保尾） | 照标记里的那句再取一次（`web_fetch` 的标记里给的是**网址**） |
| `本篇无法自动再取，请重新给出地址后再试` | 被略去的那次调用没有可用的地址或路径，没法自动取回 | 把网址或文件路径再给一次 |
| `File has <总行数> lines, showing 1-2000. To continue reading, call read_file with {"path": …, "offset": 2001, "limit": 2000}.` | 文件太长，只读了一段 | 照那句话里的 `offset` 往下读 |

> 一句话：**没有"悄悄少给"这回事** —— 少了什么、少了多少、怎么拿回来，都会写在结果里。

> DeepSeek 这一路的失败说明里**一定带着本次实际使用的地址**（就是上面括号里那一段）。先看这个地址对不对，再怀疑查询词 —— 这是"端点配错了"和"查询写错了"唯一能分开的地方。

### 想确认"DeepSeek 搜索到底开起来没有"

在仓库根目录跑这一条（**只读可用后端清单，不发起任何搜索、不花钱**）：

```
dart run scripts/deepseek_search_probe.dart
```

它会打印这次实际认出来的后端清单，最后一行是结论，例如：

```
[探针] 结论：DeepSeek 搜索可用（清单里有 deepseek，界面上的 web_search 也会出现）
```

如果最后一行说不可用，它同时会告诉你要改哪两处（地址要指向 `api.deepseek.com`，配置里要写 `"search": {"deepseek": {}}`）。加 `--no-deepseek-section` 可以模拟"完全没配 DeepSeek 搜索"的情形，加 `--session-base <地址>` 可以模拟"模型走别的网关"。

## 限制

- **联网要花钱**：搜索和抓取都要消耗搜索服务那边的额度；走 DeepSeek 那一份则算进你的模型账单（一次搜索 = 一次完整模型调用，实测 4 到 5.5 秒、约 7000 输入 + 1100 输出 token）。
- **抓不了内网和本机地址**：本机服务、路由器管理页面这类网址一律被拒。
- **搜索只走你配的服务**：一家都没配就没有搜索工具；`searxng` 这一版用不了。
- **第 `deepseek` 这一路复用的前提是地址指向 DeepSeek**：只要用到了你 `providers` 里那把密钥或那个地址（也就是你没把 `search.deepseek` 的 `api_key` 与 `base_url` 两样都写全），地址不是 DeepSeek 时它就不出现、也不发请求（见上面那条安全规矩）。自己两样都写全时按你写的走 —— 地址写错会在错误说明里看到它。
- **`web_fetch` 抓的是正文文本**，不是网页原样；需要看页面结构时它帮不上忙（那种场合用 [浏览器工具](tools-browser.md)）。
- **结果不一定准**：搜索和抓取的内容来自公网，模型会照抄其中的说法。
