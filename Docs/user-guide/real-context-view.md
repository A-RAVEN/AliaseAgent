# 真实上下文视图

## 这是什么

一个「模型这一步到底收到了什么」的视图。它显示的是**真正发出去的那一份内容**：系统提示词、工具清单、以及每一条消息的原始结构。对话区里看到的气泡是应用**显示**的样子，这一屏才是模型**读**到的东西。

## 在哪用

对话区顶部有两个标签页：

- `对话视图` —— 平时聊天看的那一屏；
- `真实上下文` —— 本页要讲的这一屏。

## 怎么操作

点 `真实上下文` 切过去。从上往下是：

1. **三块可折叠的内容**：
   - `System Prompt` —— 这次发出去的系统提示词全文；
   - `Tools (N)` —— 这次带给模型的工具清单（N 是工具个数）；一个工具都没有时显示 `(no tools)`，下面每个工具一行；
   - `Copy 原始 JSON` —— 展开后是这次请求的原始结构，用来复制出去做排查。
2. **一条条消息**，每条上面一行 `[序号] 角色` 标题（`[0]` 是第一条），下面按内容块的类型分别显示：
   - 普通文字 → 和对话视图一样的气泡；
   - 思考 → 带 💭 的卡片；
   - 工具调用 / 工具返回 → 格式化后的结构；
   - 一条消息没有任何内容块时显示 `(no content)`。

## 出错时会看到什么 / 什么时候是空的

| 现象 | 含义 |
|---|---|
| 整屏只有一句 `尚无捕获的上下文快照` | 还没有发出过任何消息，所以没有可显示的内容。发一条消息再切回来就有了 |

## 限制

- **显示的是"最近一次发出去的那一份"**：一轮对话里如果模型连续调用了好几次工具，这里显示的是那一轮的**最后一次**发送内容（内容更长的那份）。
- **它不显示磁盘上的历史**：只显示这次实际发出去的东西 —— 被压缩掉的老对话不会出现在这里（它们还在本地数据库里，只是没发出去），见 [上下文压缩](context-compaction.md)。
- **它是只读的**：这一屏不能改内容、不能重发。
