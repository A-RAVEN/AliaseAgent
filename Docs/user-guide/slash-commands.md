# 斜杠命令（slash commands）

**一句话**：在消息开头写 `/技能名`，就能让这一条消息明确按那个技能来做 —— 模型收到的会是"先加载该技能、再处理你的正文"的完整指示，而对话里看到的仍是你亲手打的字。

> 首版只做**提示展开**：不执行任何本地动作，也没有命令列表或输入补全。`/清空` 之类的写法只会被当成普通文字。

---

## 前提

- 技能已经装好并通过校验（见 [技能](skills.md)）：`~/.aliasagent/skills/<技能名>/SKILL.md`。斜杠命令用的就是这批技能的**名字**（文件夹名，小写字母、数字、连字符）。
- 技能是"当轮生效"的：新放的技能下一条消息就能用，删掉的技能下一条消息就失效（无需重启）。

## 怎么用

1. 在输入框里输入 `/技能名 正文`，例如 `/my-skill 帮我把这份日志按步骤筛一遍`。
2. 正常发送（回车或点发送按钮）。
3. 这条消息发给模型时，文本会被换成下面那套固定模板；对话视图的气泡、会话标题、落库内容仍然是你打的原文。

只发 `/技能名`（后面不带正文）也可以：模型仍会先加载技能，再按技能说明等你的下一步。

## 命中规则

必须同时满足：

- **消息以 `/` 开头**。前面有空格（` /my-skill`）就不算。
- **首段逐字等于当轮生效的技能名**。首段 = 斜杠之后到第一个空白为止的那一段。大小写敏感：`/My-Skill` 不等于 `my-skill`，不命中。
- **首段和正文之间必须有空白分界**。空白只认三种：半角空格、制表符、换行。所以 `/my-skill正文` 不命中（首段是 `my-skill正文`）。
- **全角空格不算空白**。`/my-skill　正文`（技能名后面是全角空格）里，全角空格被当成首段的一部分，首段变成 `my-skill　正文`，不等于任何技能名 —— 不命中，模型收到原文。

这些也都不命中：`/` 单独出现、`/unknown`（没有这个技能）、消息中段才出现 `/my-skill`、空消息。

**未命中一律静默透传**：不报错、不弹提示、界面毫无变化，模型收到的就是你打的原文。

## 模型实际收到什么

命中时，这条消息发给模型的文本被替换为（`<技能名>` 两处都换成命中的名字）：

```text
已按斜杠命令展开技能 "<技能名>"：请先调用 load_skill(skill: "<技能名>") 读取该技能说明并严格遵循其中的指令，然后处理下面的请求：

<你的正文>
```

正文为空时，文本就停在前缀句后的两个换行。

- 模板是代码里的**固定常量**：不能配置、不能自定义、没有 `/name --flag` 这类参数语法（`--flag` 只是正文的一部分）。
- 判定**每轮重新做**：历史消息里的 `/技能名` 每轮都按当轮的技能目录重新判定 —— 技能还在就继续展开，技能被删掉就不再展开（口径与 [技能](skills.md) 的"下一条消息就生效"一致）。
- 被压缩折叠进摘要的历史消息不再展开（摘要按原文生成）—— 这是压缩能力的既定损失，首版不补偿。

## 怎么核实

1. 发一条 `/技能名 正文`。
2. 切到对话区顶部的 `真实上下文` 视图（说明见 [真实上下文视图](real-context-view.md)）。
3. 找到那条 `[n] user` 消息 —— 它的文本就是**模型实际收到的展开版**（固定前缀句 + 两个换行 + 你的正文）。

同一时刻各处的显示口径：

| 地方 | 显示的是 |
| --- | --- |
| 对话视图的聊天气泡 | 你手打的原文 |
| 会话标题 | 由原文生成（首条消息取前 30 字符的既有规则） |
| 数据库里落库的消息 | 原文 |
| 真实上下文视图里的 user 消息 | 展开后的模板全文（模型真正读到的） |

「真实上下文」这一屏只显示**最近一次实际发出**的内容（一轮里模型连调几次工具时，显示的是最后一次），详见 [真实上下文视图](real-context-view.md)。

## 不会做的事（首版）

- 不做本地动作：`/清空`、`/新会话` 都不会执行，只当普通文字。
- 没有命令列表、命令面板、输入补全菜单。
- 没有自定义模板、没有开关：装了技能就能用，删了技能就不再展开。

## 已知限制

- 技能被删或改名后，历史里的 `/旧名` 从下一轮起不再展开（判定以当轮生效集合为准）。
- 对话视图永远显示原文，所以**从气泡上看不出这条到底展开了没有** —— 要确认就看真实上下文视图。
- 界面上"上下文占用"的 token 估算读的是落库原文、不含展开模板，所以命中斜杠命令的消息实际请求会比读数略大（每条几十 token 的量级）。
