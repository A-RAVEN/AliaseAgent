# 对话

## 这是什么

应用的主界面：左边是会话列表，右边是对话区；对话区顶部可以在「对话视图」和「真实上下文」两屏之间切换（后者见 [真实上下文视图](real-context-view.md)）。

## 在哪用

打开应用就是这一屏。左边栏从上到下是：`New Chat` 按钮、会话列表（每条显示标题）、每行末尾的删除按钮（悬停时提示 `Delete session`）。

## 怎么操作

1. **新建会话**：点左上角 `New Chat`。
2. **发消息**：在底部输入框（提示文字 `Type a message...`）里打字，然后点右边的发送按钮（悬停提示 `Send`）。**回车是换行，不是发送** —— 想换行直接按回车，想发送点按钮。
3. **看回复**：回复是流式出来的（一个字一个字出现），出现过程中输入区不可再次发送。
4. **看模型干了什么**：模型每次调用工具，对话里会插一张卡片，卡片上写着工具名和状态：
   - `Executing...`（正在执行）
   - `Done`（做完了）
   - `Error`（出错了）
   卡片展开后能看到这次调用的参数和返回结果。
5. **看模型想了什么**：带思考的过程会显示成一张带 💭 的卡片。
6. **会话标题**：新建的会话标题是 `New Chat`；你发出**第一条**消息之后，标题会自动改成那条消息的内容（只改一次，之后再发不会覆盖）。
7. **删除会话**：鼠标移到左边会话那一行，点末尾的删除按钮。
8. **切换会话**：直接点左边列表里的另一条。
9. **压缩时的提示**：对话变长以后，应用要在把请求发给模型之前先把较早的内容压成摘要，这段可能等一会儿。**这时输入框上方会出现一条提示**，写着正在做哪一步、做到第几段，压缩做完就消失：

   界面文案：`正在挑选分段主题`
   界面文案：`正在压缩较早的对话：`
   界面文案：`正在把一级摘要合成二级摘要：`

   这一条说的是**压缩**，不是模型在回话；压缩期间请求还没发出去，所以此时不会看到模型的任何字。你不动的时候（一轮结束、空闲约 2 秒后）应用也会自己压一批，同一位置会出现同样的提示，并且多一句：

   界面文案：`你发消息会让压缩先让路`

   —— 看到这句就说明这次是空闲时自动压的，你直接发消息就行，它会先让路。
10. **给模型看一张图**：两个入口，效果一样。
    - 点输入框右边、发送按钮左边的那个按钮（悬停提示就是下面这句），它会去读剪贴板里的图；
    - 或者直接按 `Ctrl+V`：剪贴板里是图片就贴图；**不是图片时仍然是普通粘贴**，文字照旧进输入框。

    界面文案：`粘贴图片`

    贴好的图会以缩略图排在输入框上方，每张右上角有个删除按钮；**可以只发图不写字**（贴完直接点发送）。发出去之后缩略图清空，图会显示在这条消息的气泡里 —— 你看到的和模型看到的是同一张。

    如果当前模型没声明能吃图（配置里的 `input_modalities` 少了 image 这一项），气泡里会多一行说明，图不会被发出去：

    界面文案：`模型未声明图片输入，本次没有发送图片`

## 出错时会看到什么

| 现象 | 含义 |
|---|---|
| 对话里出现一条以 `Error: ` 开头的回复 | 这一轮请求失败，冒号后面是原因（网络、key、服务端返回的错误等） |
| 回复里是 `No agent type configured.` | 配置里没有名字叫 `general` 的 agent，见 [配置](configuration.md) |
| 回复里是 `Provider "xxx" not found.` | agent 里写的 `provider` 在 `providers` 里找不到同名的项 |
| 点了发送但一直没有任何回复，也没有报错 | 正在生成（输入区不可用）；如果输入框上方出现了压缩提示，那是在压缩，还没开始问模型；如果长时间不动，看日志 `%USERPROFILE%\.aliasagent\logs\sidecar.log` |
| 工具卡片停在 `Error` | 那次工具调用失败了，展开卡片看返回的错误文案，对照 [文件工具](tools-file.md) / [联网工具](tools-web.md) / [浏览器工具](tools-browser.md) 里的失败说明 |
| 输入框上方出现一条红底的 `剪贴板里没有图片` | 你点了「粘贴图片」按钮但剪贴板里没有图。先把图复制到剪贴板（截图工具的"复制"、或图片右键的"复制图片"）再点一次 |
| 用户消息里的图变成 `[图片已丢失：<路径>]` | 那张图的原文件被删了、改名了或移走了。历史里只记路径，不存副本 |

## 限制

- **一次只跑一轮**：正在生成回复时发不出新消息。
- **生成中切换会话会取消这一轮**：切走之后再切回来，那一轮不会有结果。
- **正在生成时按删除会话**：这一轮同样会被取消。
- **压缩提示只覆盖压缩**：它在压缩开始后出现、压缩一结束（成功、失败、或你按下发送让它让路）就消失；**等模型吐出第一个字**的那段等待没有单独的提示，只能从"输入区不可用"看出来。
- **会话里显示的回复是应用收到并存在本地的内容**；模型**实际**看到的东西要去「真实上下文」那一屏看，两者不一定完全一样（长对话会被压缩，见 [上下文压缩](context-compaction.md)）。
- **图片在历史里只记路径**：贴进来的图会存成一个 PNG 文件（在 `~/.aliasagent/attachments/` 下），消息里只记住这个路径。所以**源文件被删、改名或覆盖之后，那条历史里的图就跟着变了或没了** —— 这是现在的做法（用户要求"先只存路径"），不是 bug。删会话**不会**删这些图片文件。
- **发出去的图会占用上下文**：每张图按 1024 token 计（服务端对每张图的上限）。图多的时候占用长得快，会更早触发压缩。
- **模型能不能看图取决于配置**：`input_modalities` 里没有 image 这一项时，图不会发出去，气泡里会多一行说明、`read_image` 工具也会直接失败（见 [配置](configuration.md)）。
